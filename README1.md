# Python Basics for Beginners 🐍

Welcome! This repository contains simple Python scripts designed to help beginners learn the core syntax and foundations of Python programming.

## 🚀 Covered Concepts
The code in this repository demonstrates the following foundational Python rules and techniques:

* **Basic Print Statements:** Displaying text on the screen.
* **Variable Declarations:** Creating variables for data types like integers (`int`), decimals (`float`), text (`string`), and true/false values (`boolean`).
* **Type Checking:** Using `type()` to see what data class a variable belongs to.
* **Control Flow:** Writing simple `if-else` conditions to make decisions.
* **Loops:** Automating repetitive tasks with `for` loops, including counting intervals and iterating through arrays/lists.
* **Zip Function:** Looping through two parallel lists at the exact same time.

## 💻 How to Use This Code
1. Make sure you have [Python installed](https://python.org) on your computer.
2. Clone this repository or copy the code files.
3. Run the file in your terminal or IDE (like VS Code):
   ```bash
   python basics.py
   ```

Feel free to tweak the variables and practice making your own loops!
